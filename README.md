# FUCKGMOS.com — website (standalone)

The original single-page site, before the Shopify theme: logo, Kid/Teen/Expert reading levels
(Kid mode shows the F GMOs logo), Kid Mode story and games, Quick Facts, Deep Dive animations,
label decoder, Eat Clean, Take Action, brand kit, merch concepts and sources.

One file, no build step. Open `index.html` in a browser, or turn on GitHub Pages
(Settings → Pages → Deploy from branch → `main` / root) to host it.
